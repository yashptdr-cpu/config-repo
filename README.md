# Config Repository

This repository stores centralized configuration files for our Spring Boot Microservices project.

## Configuration Files

- `order-service.properties` – Configuration for Order Service.
- `restaurant-service.properties` – Configuration for Restaurant Service.
- `api-gateway.properties` – Configuration for API Gateway.

## Purpose

Spring Cloud Config Server reads these configuration files from this GitHub repository and provides them to the respective microservices.

## Technology

- Java
- Spring Boot
- Spring Cloud Config Server
- GitHub
